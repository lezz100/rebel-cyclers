# Project Brief — Rebel Cyclers

Version 1.0 · October 2026

## Identity

**Name:** Rebel Cyclers  
**Tagline:** Ride together. Explore further.  
**Tone:** Community-first, performance-aware, adventure-oriented. Warm and direct — not corporate.

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Home — hero, intro, featured rides, CTA |
| `/about` | Club story, mission, values, riding culture |
| `/rides` | Ride cards + individual ride detail pages |
| `/members` | Rider spotlights and leadership |
| `/achievements` | Verified milestones, results, records |
| `/gallery` | Filterable photo collection + lightbox |
| `/contact` | Contact form + join invitation |

## Scope boundaries

- Frontend only — no backend, no database, no authentication.
- Contact via `mailto:` workflow.
- No invented club history, statistics, race results, or testimonials.
- Placeholder content clearly marked until real assets and information are supplied.

## Technology

- Next.js 16 App Router · TypeScript · Tailwind CSS v4
- Motion for React · shadcn/ui (selective)
- pnpm
